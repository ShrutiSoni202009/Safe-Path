Safe Path is a Python console-based travel safety application designed to help users manage their travel records, assess travel risks, and access useful safety-related information.
🚀 Features
Add Travel Record – Add and save travel details.
View Travel History – View previously saved travel records.
Search Travel Record – Search for a specific travel record.
Delete Travel Record – Remove unwanted travel records.
Risk Prediction – Predict the potential risk associated with travel.
Weekly Safety Report – View a weekly report related to travel safety.
Emergency Contact – Store or access emergency contact information.
SOS Message – Generate an SOS message for emergencies.
Unsafe Area Information – Check information about unsafe areas.
Safety Badge – Receive a safety badge based on safety-related activities.
Safety Tips – Get useful tips for safer travel.
Exit – Exit the application safely.
🛠️ Technologies Used
Python
JSON
📂 Project Files
main.py – Main Python program containing the application logic.
travel_data.json – Stores travel-related records.
unsafe_places.json – Contains information about unsafe locations.
